# 影之刃零 · 存档工具

《影之刃零》（Phantom Blade Zero / ProjectPBZ）离线存档修改器。单文件 GUI，不注入进程，不联网。

## 一键功能

| 功能 | 说明 |
|---|---|
| **一键升级全部技能** | 两套能力树共 64 个节点全部点亮（黑石 / 沙齿琥珀 / 忆花 / 榕树之心） |
| **一键升级全部武器 / 影之武装到满级** | 已有的主武器与影之武装全部提到 30 级 |
| **一键开当前小地图全部铃铛** | 只开当前所在地那一组的铃铛，不动其它区域 |
| **一键开大地图全部铃铛** | 13 个区 194 个铃铛 + 世界地图遮罩全开 |
| **一键获得全部武器 / 影之武装** | 按游戏物品表补齐 33 把主武器 + 27 件影之武装 |
| **一键获得全部道具 / 读物** | 按游戏物品表补齐 640 件道具（含 15 件读物 Page_*） |

## 任务

列出游戏里全部 83 个任务（主线 10 / 支线 15 / 收集 10 / 教程 12 / 传闻 36），带中文名与实时状态：

```
类别   任务        内部 ID                  状态
主线   逆流而上     MainCh1-NiLiuErShang     ✔ 已完成
主线   破局        MainCh3-PoJu             ○ 进行中  ← 追踪
支线   红房子       HongFangZi               · 未开始
传闻   凶斧        XiongFu                  ✔ 已完成
```

- **完成选中**：任意一条，未开始的也能标完成
- **完成全部进行中**：只处理存档里已有的「进行中」任务
- **全部标完成（含未开始）**：83 个全标完成，未开始的会新建条目
- **仅看未完成 / 全部**：列表筛选

## 主线

10 个主线按时序排列，标出章节、状态和当前追踪：

```
顺序  章节                    任务        状态
 1   第一章 逆流而上          逆流而上    ✔ 已完成
 5   第二章 林中血，镜中蛇     死镇        ✔ 已完成
10   第三章 英雄？罪人？       破局        ○ 进行中  ← 当前追踪
```

- **设为追踪**：只改任务指针，不动任何进度
- **推进到此**：前面主线全标完成 + 目标设为进行中 + 切换追踪

## 结局 / 收集

四个结局记录（龙吟 / 湮灭 / 决战 / 饮恨）可改，只影响「查看轮回记录」里显示的结果。

**收集度改为 100** 会同时把能枚举的收集内容填满：

| 项目 | 内容 |
|---|---|
| 图鉴·已发现敌人 | 补全到 169 个敌人类路径 |
| 特典·美术 | 148 条全部解锁 |
| 特典·音乐 | 66 条全部解锁 |
| Boss 讨伐 | 已有 boss 补齐难度 0-4 的讨伐记录 |
| 收集度数字 | `CycleRecords` / `FirstClearRecord` 的 Completion 改成 100 |

**改游戏时长**：支持 `12h34m56s`、`1:02:03`、`3600`（秒）三种写法。

## 存档管理

- **存档槽选择**：列出「载入存档」界面里的全部槽，字段与游戏一致（标题 / 难度 / 时长 / 时间），二周目「六十六天」存档也会列出来，额外显示轮回数、剩余天数
- **删除选中**：从存档文件里移除指定槽，自动修正「继续游戏」指向
- **还原最近备份**：每次写盘前自动备份 `.bak-时间戳`，一键回滚
- **试运行**：不写盘，只看会改什么
